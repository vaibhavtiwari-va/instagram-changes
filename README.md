# Instagram Clone

This is a simple Instagram clone project built using HTML, CSS, and JavaScript. It includes basic features like a feed, reels, and a sidebar with user suggestions.

## Features

- **Reels Section**: Displays video reels with a restriction to view only 5 reels.
- **Feed Section**: Shows posts with images, usernames, and action buttons (like and comment).
- **Sidebar**: Provides user suggestions for connections.
- **Responsive Design**: The layout is responsive and adjusts to different screen sizes.

## New Functionality

- **Reels Restriction**: Users can scroll through a maximum of 5 reels. After reaching the limit, further scrolling is disabled, and an alert is displayed.

## Project Structure

```
instagram/
├── index.html       # Main HTML file
├── style.css        # CSS file for styling
├── script.js        # JavaScript file for functionality
```

## How to Run

1. Clone the repository:
   ```bash
   git clone <repository-url>
   ```
2. Open the `index.html` file in any modern web browser.
